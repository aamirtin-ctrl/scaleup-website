# Construction progress media

Drop site photos (.jpg/.webp) and videos (.mp4) into this folder, then add one
line per file to the PROGRESS_MEDIA list at the top of main.js:

  { type: 'image', src: 'assets/progress/2026-08-slab.jpg', date: 'AUG 2026', caption: 'Building A slab poured' },
  { type: 'video', src: 'assets/progress/2026-09-framing.mp4', date: 'SEP 2026', caption: 'Framing week 2 flyover' },

Newest first. Keep videos under ~20MB (compress with Handbrake or ask Claude).
